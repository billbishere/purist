# Milestone 2 verification

## Native DSD on the Topping D50 (ASIO), 2026-10-25

`run.cmd "E:\Music\Michael Jackson - Thriller - 1982, DSF 128 (tracks), TAV"` with output = ASIO · Topping USB
Audio Device. The user confirmed by ear: "Thriller plays fine as DSD". The deck read
`DSF  DSD128  5.6448 MHz  STEREO  ● BIT-PERFECT` and `DSD128 > native DSD (DSD_INT8_MSB1) @ 5.6448 MHz`.
Before the DAC was switched on, the device-loss banner showed "Topping USB Audio Device is not available — check
it is on and connected. Retrying…", and playback started by itself once the D50 came on.

Real-file checks (read-only): all 9 Thriller DSF128 tracks probe as DSD128; the Ted Nugent SACD ISO's 9 tracks
decode to their declared lengths with byte-identical seeks.

Note: the deck shows the ASIO DSD buffer in driver samples (65536 bits); label units in a later UI pass.

## WASAPI exclusive on the Topping D50, 2026-10-25

Output = WASAPI · Speakers (2- TOPPING USB DAC), album `Enigma - MCMXC a.D. [FLAC 24-96]`. The user confirmed it
plays fine and shows ● BIT-PERFECT. Found during the check and fixed (7cbc500): the output list was read only at
start-up, so a DAC switched on later was missing; Settings now re-reads it each time it opens. DSD over WASAPI was
refused with the DoP opt-in message as designed (DoP off by default per device).
