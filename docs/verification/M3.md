## Library end to end, 2026-10-26 (Task 31)

Scripted run against an empty profile (`-Dpurist.profile` pointing at a scratch folder), with no UI, using the same
`AppLibrary`, `FoobarImport` and `PlaylistStore` the window uses. foobar2000's profile was only read.

1. Import from foobar2000 found 3 folders (`C:\Users\me\Music`, `C:\Users\me\OneDrive\Music`,
   `E:\Music`) and 1 playlist (`Default Playlist`, 10 tracks). The first start reported `firstRun = true`, so the
   window opens on DRIVES.
2. The first scan finished all 3 folders: **7,888 tracks in 161 albums, 98.7 s** (the first two folders hold no audio
   files; `E:\Music` is a spinning disk and gave 7,838 added and 42 unreadable files, kept as greyed rows and
   logged to `scan-errors.log`).
3. Restart on the same profile: `firstRun = false`, and the incremental rescan of all 3 folders with no change
   finished in **0.24 s** (7,880 unchanged), well under the 10 s limit.
4. The imported playlist came back from `playlists\` with its 10 tracks.
